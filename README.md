# 财富罗盘

个人的财富记录与规划工具（PWA，可安装到手机桌面离线使用）。

## 四个 Tab

- 📊 **总览**：净资产、总资产 / 总负债 / 负债率、资产构成饼图、固定与投资净资产拆分、净资产月度趋势；底部可展开「📍 国内家庭对标」
- 🧾 **账目**：资产与负债明细的增删（金额单位：万元）
- 💰 **收支**：每月收入来源与支出项（金额单位：元），自动算储蓄率与收支占比
- 🎯 **规划**：储蓄目标与达成年限测算（悲观 / 中性 / 乐观三档年化）；「🩺 财务健康评估」与「🚀 副业增值项目」默认折叠，点击展开

## 数据与备份

- 所有数据只保存在本机浏览器的 localStorage（key：`localgoal.v1`），不会上传到任何地方
- iOS 长期不用可能清理浏览器数据，请在「总览」页底部的备份区定期**导出**，把文本粘贴保存到备忘录；换设备时再**导入**恢复
